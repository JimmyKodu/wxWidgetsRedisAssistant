# Redis Assistant v1.0.0 - Windows Release

This directory will contain the Windows x64 release package.

After building, you will find:
- `RedisAssistant-1.0.0-windows-x64.zip` - Compressed release package
- `RedisAssistant-1.0.0-windows-x64/` - Extracted package contents

## Contents
- `RedisAssistant.exe` - Main executable
- `README.txt` - User instructions
- `*.dll` - Required DLL files (wxWidgets, hiredis, Visual C++ runtime)

## Running
1. Extract the ZIP file
2. Navigate to the extracted folder
3. Double-click `RedisAssistant.exe`
